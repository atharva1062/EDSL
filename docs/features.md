# 🚀 Key Features

## 👤 User Management

| Feature | Description |
|---|---|
| Student Registration | Sign up with college email |
| Login / Logout | Secure JWT-based sessions |
| Student Profile | Manage personal info and listings |
| College Verification | Email domain verification to ensure only students join |

---

## 🛒 Marketplace

| Feature | Description |
|---|---|
| Create Listings | Post items for sale, exchange, or donation |
| Upload Product Images | Multiple image uploads per listing |
| Search Products | Full-text search across all listings |
| Filter by Category | Browse books, electronics, hostel items, etc. |
| View Product Details | Detailed page with images, price, and seller info |

---

## 💬 Communication

| Feature | Description |
|---|---|
| Contact Seller | Quick inquiry button on every listing |
| Chat Between Students | Real-time or message-based chat |
| Seller Information | View seller profile and their other listings |

---

## 🔄 Transactions

| Feature | Description |
|---|---|
| Buy / Sell Requests | Formal request system for initiating transactions |
| Exchange Items | Propose item swaps with other students |
| Donation Option | Mark items as free to give away |
| Transaction History | Track all past and ongoing deals |

---

## 🛡️ Safety & Trust

| Feature | Description |
|---|---|
| User Verification | College email domain check |
| Report Listing | Flag inappropriate or misleading posts |
| Report User | Report suspicious or abusive users |
| Admin Moderation | Dedicated admin panel to review reports and manage content |
