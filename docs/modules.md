# 📦 Core Modules

CampusSwap is structured around **9 core modules**, each responsible for a distinct part of the platform.

---

## 🏠 1. Dashboard Module

**Purpose:** Central overview of the marketplace

- Featured and recent listings
- Quick stats (active listings, categories)
- Personalized recommendations (future)
- Navigation hub for all modules

---

## 👥 2. Users Module

**Purpose:** Manage student accounts and profiles

- User registration and login
- Profile management (name, college, bio, avatar)
- View other students' profiles and listings
- Account verification status
- Role management (student / admin)

---

## 📦 3. Listings Module

**Purpose:** Core buy/sell/exchange/donate functionality

- Create, edit, delete listings
- Set listing type: Sell | Buy | Exchange | Donate
- Upload multiple product images
- Mark listing as active / sold / closed
- View listing history

---

## 🗂️ 4. Categories Module

**Purpose:** Organize products for easy browsing

- Pre-defined categories: Books, Electronics, Hostel Items, Stationery, Clothing, Tools, Misc
- Category-based browsing
- Category icons and descriptions

---

## 🔍 5. Search Module

**Purpose:** Help students find what they need quickly

- Full-text keyword search
- Filter by category, price range, listing type
- Sort by: newest, price (low-high, high-low)
- Search history (future)

---

## 💬 6. Chat Module

**Purpose:** Enable direct communication between buyers and sellers

- Buyer initiates chat from listing page
- Message threads per listing
- Read/unread status
- Notification on new messages

---

## 💳 7. Transactions Module

**Purpose:** Manage and track purchases and exchanges

- Send buy/exchange request to seller
- Seller accepts or declines
- Transaction status: Pending → Accepted → Completed
- Full transaction history for each user

---

## 🔔 8. Notifications Module

**Purpose:** Keep users informed of important updates

- New message received
- Buy/exchange request received
- Request accepted/declined
- Listing reported (for admin)
- System announcements

---

## ⚙️ 9. Admin Module

**Purpose:** Platform management and moderation

- View all users and listings
- Review and action reports
- Ban/unban users
- Remove inappropriate listings
- Platform statistics dashboard
