# 🛠️ Tech Stack

## Overview

CampusSwap is built with a modern, beginner-to-intermediate-friendly stack that is industry-standard and scalable.

---

## 🎨 Frontend

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure and semantic markup |
| **CSS3** | Styling, responsive design |
| **JavaScript (ES6+)** | Client-side interactivity |
| **React.js** | Component-based UI framework |
| **React Router** | Client-side routing / navigation |
| **Axios** | HTTP requests to the backend API |

---

## ⚙️ Backend

| Technology | Purpose |
|---|---|
| **Node.js** | JavaScript runtime environment |
| **Express.js** | Web framework for building REST APIs |
| **JWT** | Stateless authentication tokens |
| **bcrypt** | Secure password hashing |
| **Multer** | File/image upload handling |
| **dotenv** | Environment variable management |
| **CORS** | Cross-origin request handling |

---

## 🗄️ Database

| Technology | Purpose |
|---|---|
| **PostgreSQL** | Primary relational database |
| **Prisma ORM** | Type-safe database client and schema management |

---

## 🚀 Deployment

| Service | Purpose |
|---|---|
| **Vercel** | Frontend hosting (React app) |
| **Render / Railway** | Backend hosting (Node.js API) |
| **Supabase / Neon** | Hosted PostgreSQL database (optional) |

---

## 🔧 Development Tools

| Tool | Purpose |
|---|---|
| **VS Code** | Code editor |
| **Postman** | API testing |
| **Git & GitHub** | Version control |
| **Prisma Studio** | Visual database browser |
| **npm** | Package management |

---

## Why This Stack?

- ✅ **JavaScript end-to-end** — same language on frontend and backend
- ✅ **Prisma** makes database work easy and type-safe
- ✅ **React** is industry standard for modern UIs
- ✅ **PostgreSQL** is reliable and structured (perfect for marketplace data)
- ✅ **Free deployment** on Vercel + Render
